## 0.1 通用约定

| 项 | 约定 |
|----|------|
| Base URL | `/api`（nginx 反代 `location /api/` → backend:8000） |
| WebSocket | `/ws/messages`（**不带** `/api` 前缀，nginx 单独反代升级头） |
| 数据格式 | 请求/响应均为 JSON；列表接口直接返回数组（无分页包装） |
| 错误格式 | FastAPI `HTTPException`：`{"detail": "<中文可读原因>"}`，状态码 400/404/500/502 |
| 金额 | 一律「分」（`price_cent`），前端展示时 `/100` |
| 时间 | `message_time` 为毫秒时间戳（闲鱼侧全是 ms）；`last_login_at`/`occurred_at` 为 ISO datetime；DB 时间戳统一 Python 本地时钟 |
| 外部 ID | 闲鱼侧重外部 ID（unb/商品/订单）一律字符串，不转数字 |
| 鉴权 | 第一阶段无鉴权（内网部署，nginx 唯一对外）；上服务器前需补 |

## 2. 账号（auth，阶段 4-1）✅ 待小号实测

### `GET /api/accounts` — 账号列表（脱敏）
只暴露昵称/状态，**不含任何登录态**（Cookie 由后端会话池管理，前端与 Agent 都不碰）。

响应字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 内部账号 ID（后续接口的 account_id） |
| nickname | string\|null | 昵称 |
| external_uid | string | unb（闲鱼用户 ID） |
| status | int | 0 停用 / 1 启用 |
| cookie_status | int | 0 待校验 / 1 正常 / 2 过期（RGV587 风控不误标，只入滑块流程） |
| fish_shop_user | bool | 是否鱼小铺账号（发布接口两套） |
| last_login_at | datetime\|null | 最近登录时间 |

### `POST /api/accounts/qr-login` — 生成扫码登录二维码
响应：`{"session_id": "<uuid>", "qr_image": "data:image/png;base64,..."}`（qr_image 为 data URI，直接放 `<img src>`）。
失败：502 `{"detail": "..."}`（二维码获取失败）。

### `GET /api/accounts/qr-login/{session_id}` — 轮询扫码状态
前端 1s 一次。状态机：`new`（等待扫码）→ `scaned`（已扫待手机确认）→ `confirmed`（成功）｜`expired`｜`cancelled`｜`verification_required`｜`error`。

`confirmed` 时后端自动：Cookie AES-GCM 加密入库 + 会话池注册 + 拉起该账号 WS 监听，并在响应里附带：

```json
{ "status": "confirmed", "account_id": 1, "nickname": "小号A" }
```

## 5. 发货（delivery，品类 A 卡密）✅

### `GET /api/delivery/records?limit=` — 发货记录
最近优先，`limit` 默认 50 上限 200。

| 字段 | 类型 | 说明 |
|------|------|------|
| order_id | string | 订单号（唯一约束兜底幂等，每单最多一条成功） |
| delivery_mode | string | 发货形态（当前仅 kami） |
| status | string | 状态机：pending → message_sending → message_confirmed → platform_confirmed → success；另有 failed / skipped；**unknown 态永不自动重发** |
| card_item_id | int\|null | 消耗的卡密 |
| fail_reason | string\|null | 失败/跳过原因（中文可读） |
| receiver_info | object\|null | 收件信息快照 |

### `GET /api/delivery/cards` — 卡密组库存

| 字段 | 类型 | 说明 |
|------|------|------|
| id / name | int / string | 卡密组 |
| goods_id | int\|null | 绑定商品（品类 A 发货时按 goods_id 找组） |
| total_count / used_count | int | 冗余计数 |
| available | int | 剩余（status=0 的 item 实时统计） |
| low_stock | bool | available ≤ alert_threshold 告警 |

### `POST /api/delivery/card-groups` — 新建卡密组
Body：`{"name": "必填≤128字", "goods_id": null, "alert_threshold": 5}`。
响应：`{"id": 1, "name": "..."}`；组名重复 400。

### `POST /api/delivery/card-groups/{group_id}/items` — 批量导入卡密
Body：`{"lines": "卡号----卡值\n卡号2\n# 注释行忽略"}`（每行 `卡号----卡值`，卡值可省略；空行/`#` 注释忽略；**重复卡号自动跳过**）。
响应：`{"added": 新增数, "total_count": 组内总数}`；组不存在 404。

### `POST /api/delivery/rules` — 建/改发货规则
同账号+同商品维度只保留一条（先查后更，无则插入）。

Body：

| 字段 | 默认 | 说明 |
|------|------|------|
| account_id | 必填 | 账号 |
| goods_id | null | 空 = 账号级默认规则；商品级优先于账号级 |
| delivery_mode | "kami" | 当前仅 kami |
| trigger_on_pay | 1 | 付款即发 0/1 |
| max_delivery_per_day | 200 | 每日上限（按账号当日 success 数） |

响应：`{"id": ..., "account_id": ..., "goods_id": ...}`。

> 发货链路（自动，✅ 代码+单测完成，待小号实测）：WS 付款消息（contentType=26 + 关键词）→ ORDER_PAID 事件 → 查商品（未登记不发货）→ 品类分流（B 只留痕+通知）→ 规则 → 卡密组取卡 → 发买家 → 可选平台确认发货（`delivery_auto_consign`）。
> 自动发货的完整前置配置：`POST /delivery/rules`（规则）+ `POST /delivery/card-groups`（组）+ `POST .../items`（卡密）+ 商品 external_goods_id 与闲鱼侧一致。

## 6. 设置（settings，内存不持久化）✅

### `GET /api/settings/reply-mode` — 查询 AI 回复配置
响应：`{"mode", "max_daily_replies", "blocked_keywords", "model", "llm_configured"}`。
`llm_configured=false` 表示未配 OPENAI_API_KEY，auto 模式不会真正生成回复。

### `PUT /api/settings/reply-mode` — 切换回复模式（免重启，实测用）
Body：`{"mode": "auto|hybrid|manual"}`；非法值 400。只改内存 settings，重启回 .env 默认。

## 7. WebSocket `/ws/messages` — 实时事件推送 ✅

订阅后端事件总线，前端拿规范化字段（**剥掉 rawPayload**）。

- 连接：`ws(s)://{host}/ws/messages`（注意：**不带 /api 前缀**；vite/nginx 均按 `/ws/` 反代并带升级头）；
- 心跳：服务端每 30s 推 `{"type": "heartbeat"}`，前端忽略即可；
- 断线：前端自行重连（骨架版总线无 unsubscribe，重连会累积空 handler，只空转）。

推送消息格式：

```json
{
  "type": "message_received | order_paid | order_created | cookie_expired",
  "account_id": 1,
  "occurred_at": "2026-09-15T10:00:00",
  "payload": { }
}
```

| type | 含义 | payload 关键字段 |
|------|------|-----------------|
| message_received | 新消息（含文本/图片） | senderUserId / senderUserName / contentType / msgContent / xyGoodsId 等 |
| order_paid | 买家已付款（触发品类 A 自动发货） | orderId / orderKey / xyGoodsId / buyerUserId / buyerName |
| order_created | 新订单（品类 B 人工履约通知） | orderId / orderKey / xyGoodsId / buyerUserId / buyerName / goodsTitle |
| cookie_expired | 登录态失效（需重新扫码） | — |
